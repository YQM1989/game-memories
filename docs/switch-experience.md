# Switch 游戏回忆同步

Steam 和 Switch 2 共用一个桌面应用。Switch 账号相册通过应用自带的 nxapi 发布客户端读取；后台工具按需启动，完成后退出，无需手动启动另一个窗口或终端。

## 使用

1. 切换到 Switch 2 → Settings，填写共享的 Obsidian 仓库根目录。默认笔记目录为 `00_输入源/50_我是谁/Switch体验记录`，附件目录为 `附件/Switch体验记录`。
2. 阅读数据流向并同意第三方认证，然后连接 Nintendo 账号。已有钥匙串授权可以直接使用，不需要重新登记 nxapi 客户端或填写兼容标识。
3. 首次连接通过 Nintendo 官方网页登录和 PKCE 授权；复制官方「使用此账号」按钮链接，在应用中完成连接。授权链接不要发到聊天或保存到笔记。
4. 在 Dashboard 点击「开始同步」。程序自动读取当前云端相册，只下载新增截图／视频，按游戏和原始拍摄日期追加到 Obsidian。
5. 已同步项目按相册标识去重。相同游戏、拍摄时间、类型与文件内容的重复上传合并显示，并保留每个相册标识，后续不会重复下载；不同拍摄时间仍保留独立回忆。
6. 在 Obsidian 右侧独立输入框补写「我的感想」，离开输入框自动保存，也可点击保存或按 ⌘/Ctrl+Enter。该功能复用已启用脚本能力的 Dataview；未启用的仓库保留普通 Markdown 感想。感想保存于游戏笔记的独立属性，不在可执行代码或浏览器持久存储中。同步保留已有文字；海报更新仅修改生成的海报区域。已有游戏海报保留，新游戏可在游戏列表补选本地 JPG／PNG 海报。

「扫描相册」是可选的只读查看，不是一键同步的前置步骤。同步按按钮运行一轮，不持续监控。停止按钮可中止后台读取或后续下载。

## 删除无用记录与恢复

在感想区点击「删除这条记录」，再点「确认删除」，这一条截图／视频从正文移入笔记底部折叠的「已删除记录」。未保存的感想会先保存，出现编辑冲突时停止删除；其他记录继续保留。误删后展开「已删除记录」并点击「恢复这条记录」。

删除状态随游戏笔记保存，同步状态继续记住全部相册来源 ID，重复上传的来源别名也沿用去重处理；后续同步不会重新导入已删除项，新增内容仍正常追加。本地附件与感想保留用于恢复，Nintendo 云相册保持原样。该操作整理笔记显示，不释放附件占用空间。

该按钮与独立感想区共用 Dataview JavaScript 组件；升级现有组件即可使用，原游戏笔记无需重写。应用中的已归档数量不计入已删除记录，恢复后重新计入。

日常查看、补写感想和删除记录可直接使用 Obsidian「阅读视图」，无需打开笔记编辑器。编辑／实时预览中可能显示 `%% switch-… %%` 内部定位标记；点击右上角书本图标或按 ⌘/Ctrl+E 切换阅读视图即可隐藏，标记应保留以支持后续同步。

仅处理已上传到 Nintendo Switch App 云端相册的内容，不等同于读取主机全部本地素材。内部接口或认证服务失败时停止并提示，不将失败冒充空相册；限流时记录冷却。

## 凭据与数据流向

- Nintendo 官方登录／令牌接口与本机程序通信；相册请求由本机发送到 Nintendo API。
- nxapi 远程服务生成认证参数并处理请求加密与响应解密，因此会处理 Nintendo 登录令牌、部分账号资料及相册元数据。
- 媒体文件从 Nintendo 返回的 CDN 地址直接下载。
- 发布客户端保留其原始认证实现与身份，调用者额外标识本项目。没有把其他应用的身份复制到本项目自建认证代码。
- Nintendo 会话与有效期内的访问缓存经本机管道传递，由 Rust 保存到 macOS 钥匙串，不写普通配置、命令参数、Obsidian、日志或 React 界面。
- 上游默认文件账号缓存改接到内存；默认调试日志、环境 .env 读取和自动更新检查关闭。公开配置缓存归属于本应用。
- 上游相册命令中未使用的好友、聊天、游戏服务、活动、公告及额外自身资料读取已在相册子进程内禁用。认证所需的 Nintendo 账号资料仍会读取。

移除登录信息保留已归档内容；它不等于在 Nintendo 服务端撤销所有会话。

## 开发与打包

`npm run switch:prepare` 使用 `tools/nxapi-client` 的独立锁文件准备 `nxapi@1.6.1-next.257`。不会安装全局工具，也不执行依赖安装脚本。macOS 打包包含该客户端、依赖和独立 Node 运行时，安装后的应用不依赖项目 checkout 或系统 Node。

nxapi 源码定位：<https://github.com/samuelthomas2774/nxapi/tree/47c9d35d9d51d33e62dd6d3733b616e0ad31b02b>。nxapi 与存储适配文件 `nxapi-preload.mjs` 使用 AGPL-3.0-or-later，许可全文与依赖许可随包保留。仓库包含集成与适配源码，当前验证对象为本机安装包；公开组合安装包需核对对应源码及许可证要求，不以子进程方式断言组合分发不受许可证约束。

原自建认证实现暂保留供协议测试和诊断；账号同步默认走发布客户端，旧客户端设置不再用于此流程。本地导入兼容路径保留。

当前账号存储桥接支持 macOS；Windows 账号存储与安装包尚未完成适配和真机验证。

技术测试、真实相册运行、桌面交互及用户本人验收分别记录，不以模拟测试代替真实使用。此前已正式导入 37 条相册记录、32 份独立媒体至 8 份游戏笔记，后续同步需验证新增量与重复执行保留已有内容。
